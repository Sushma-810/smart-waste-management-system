About the Project

Smart Waste Management System is a web application that helps users report waste-related problems easily.

Users can submit complaints with images, and administrators can view, manage, assign, and update complaint statuses.

Technologies Used

Frontend: React.js, HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: Amazon RDS (PostgreSQL)

Cloud: AWS EC2, S3, IAM

DevOps: Docker, Nginx, Linux, Git, GitHub

Key Features

User Login and Authentication

Submit Waste Complaints

Upload Complaint Images

Track Complaint Status

Admin Dashboard

Manage Complaints

AWS Services

EC2 – Application Hosting

S3 – Image Storage

RDS – Database Management

IAM – Access Management
